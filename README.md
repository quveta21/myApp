# SpendWise

SpendWise is a mobile application for managing personal finances. It helps users track income and expenses, manage monthly budgets, and understand their spending habits.

## Features

- User authentication using JWT.
- Create, edit, delete, and view income and expense transactions.
- Organize transactions by categories.
- View transaction details using a master-detail interface.
- Track monthly budgets and spending statistics.
- Receive real-time notifications when approaching budget limits.
- Store data locally for offline access.
- Browse transaction history using infinite scrolling.
- Attach receipt photos to transactions.
- Save transaction locations and display them on a map.
- Export financial reports.

## Technologies

- Ionic
- Angular
- REST API
- WebSockets
- JWT Authentication
- SQLite

## Goal

The goal of SpendWise is to provide a simple and intuitive way to manage personal finances and develop better spending habits.
